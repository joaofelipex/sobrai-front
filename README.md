# Sobrai: front-end

Aplicação Angular 21 do Sobrai. A documentação completa (funcionalidades, arquitetura, como rodar e testes) está no [README principal](../README.md).

```bash
npm install
npm run dev     # http://localhost:3000, também acessível pela rede local
npm run build
```

A API (`../sobrai-back`) precisa estar rodando na porta 3001. O front usa o mesmo endereço da página para chamá-la, então funciona também quando aberto de outro aparelho da rede.
